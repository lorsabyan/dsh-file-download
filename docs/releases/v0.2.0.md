Download entire folders as ZIP archives from DeepSeek Harness.

- Download icons beside directory rows, plus **Download ZIP** in the Files toolbar for the current root.
- Nested paths, hidden files, empty folders/files, Unicode names, and original file bytes.
- Immediate browser save pickers where supported, sequential streaming, cancellation, progress, CRC-32, and source-change checks.
- Clear errors for incomplete listings, symlinks/special entries, unreadable files, unsafe archive paths, and unsupported archive sizes.

## Install or upgrade

Download `dsh-file-download-0.2.0.tgz` and `SHA256SUMS`, verify the archive, then run on the Harness host using your server's profile:

```sh
dsh plugin --profile web add ./dsh-file-download-0.2.0.tgz
```

Restart Harness and refresh the browser. Replace `web` with your active profile.

## Compatibility

Harness baseline remains **0.2.0-rc.2**. Supported save-picker browsers, such as Chrome/Edge in a secure context, stream folder ZIPs directly to a chosen file. Browsers without this API require the complete ZIP to fit **32 MiB**.

ZIPs store contents without recompression and retain the selected folder as their top-level directory. Limits: fewer than **4 GiB** total bytes, **10,000 entries**, **64 levels** below the root, and **8 MiB** ZIP metadata. Harness's own listing cap also applies; truncated listings stop the download rather than omitting files.

See [compatibility](https://github.com/lorsabyan/dsh-file-download/blob/main/docs/compatibility.md#folder-archives) for the full behavior and limitations.
