Download original files directly from DeepSeek Harness's Files tree and native preview toolbar.

The initial release preserves filenames and file contents, adds cancellation and transfer status, and streams large files through supported browser save dialogs. It uses Harness's existing authenticated file service and adds no runtime dependencies or server routes.

## Install

Download the attached `dsh-file-download-0.1.0.tgz`, then run this on the Harness host using your web server's profile:

```sh
dsh plugin --profile web add ./dsh-file-download-0.1.0.tgz
```

Restart the Harness web server and refresh the browser. Replace `web` if you use a different profile. Verify the archive with the attached `SHA256SUMS` before installation.

## Compatibility

- Qualified against Harness **0.2.0-rc.2** and Chrome.
- Files up to **32 MiB** use normal browser downloads.
- Larger files require `showSaveFilePicker()` in a supported secure browser context, such as Chrome or Edge.
- Preview uses the official action slot; Files uses a native row adapter that may need updating if Harness changes its markup.

The archive is prebuilt and needs no install-time compilation. The package is not published to npm. See the [README](https://github.com/lorsabyan/dsh-file-download#readme) for usage and [compatibility notes](https://github.com/lorsabyan/dsh-file-download/blob/main/docs/compatibility.md) for limitations.
